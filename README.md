# Customer Data Analysis Using Excel

## Project Overview
This project demonstrates customer data cleaning, analysis, and dashboard creation using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- Charts and dashboard visualization

## Data Cleaning
- Standardized customer names and text formats.
- Trimmed unnecessary spaces.
- Converted sign-up dates to the correct date format.
- Checked for missing values.
- Identified and removed duplicate records using Record ID.

## Analysis and Visualizations
Created PivotTables and four charts to explore:
1. Total amount by payment status.
2. Number of customer records by payment status.
3. Total amount by city.
4. Customer sign-ups by month.

## Project Outcome
Built an Excel dashboard to summarize customer records, payment statuses, amounts, and sign-up patterns.

## File
The Excel workbook contains the cleaned data, analysis, PivotTables, and dashboard.
